## Healthcare Dashboard

### About Dashboard
This dashboard provides a complete overview of healthcare data such as patient details, appointments, doctor performance, revenue, and hospital operations. It helps users monitor healthcare KPIs and make better decisions through interactive visualizations.

### Data Source
- SQL Database
- Excel Files

### Features
- KPI cards for total patients, revenue, and appointments
- Doctor and department performance analysis
- Patient admission and discharge tracking
- Interactive filters and slicers
- Trend analysis using charts and graphs
- Clean and responsive dashboard design

### Tools & Technologies
- Power BI
- SQL
- Excel
- DAX
- Power Query
